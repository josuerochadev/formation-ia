## À propos

Archive des 28 exercices et des 6 fiches de synthèse réalisés pendant la formation AJC (10 jours / 70h, 2025). La formation couvre le cycle complet : fondamentaux LLM, conception d'agents, RAG, déploiement, tests et optimisation.

Le projet fil rouge (agent Luciole) a été extrait dans son propre dépôt : [josuerochadev/luciole](https://github.com/josuerochadev/luciole).

Projet réalisé en équipe avec Alex Dubus, Zhengfeng Ding et Stéphanie Consoli.

## Structure

```
├── exercices/       # 28 exercices pratiques répartis en 6 modules
│   ├── module1/     # Fondamentaux IA & LLM
│   ├── module2/     # Conception d'agents
│   ├── module3/     # Implémentation Python
│   ├── module4/     # RAG & FastAPI (code source : rag/)
│   ├── module5/     # Tests & Déploiement (atelier, soutenance)
│   └── module6/     # Optimisation & Caching (cascade/, reranking/, prompt_caching/)
└── fiches/          # Fiches de synthèse par module (Markdown)
```

## Modules

| Module | Thème | Contenu |
|---|---|---|
| Module 1 | Fondamentaux IA & LLM | 5 exercices — tokens, hallucinations, comparaison LLM, paramètres, stratégies de prompt |
| Module 2 | Conception d'agents | 4 exercices — matrice de priorisation, patterns d'agents, spécification des outils, cahier des charges |
| Module 3 | Implémentation | 5 exercices — structure projet, JSON structuré, ReAct, mémoire, debugging |
| Module 4 | RAG & FastAPI | 6 exercices + code — pipeline RAG (ChromaDB, pdfplumber, corpus CNIL), API FastAPI, robustesse, multimodal, sécurité |
| Module 5 | Tests & Déploiement | 6 exercices + atelier — tests unitaires, intégration, LLM-as-judge, Docker, monitoring, soutenance |
| Module 6 | Optimisation & Caching | 2 exercices + code — Langfuse, prompt caching, cascade routing, re-ranking Cohere |
